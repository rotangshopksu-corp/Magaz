# Адмін-панель KsuШик + Supabase

## Что входит

- `admin.html`, `admin.css`, `admin.js` — вход и управление категориями/товарами.
- `supabase-config.js` — адрес проекта, публичный ключ и email администратора.
- `supabase-setup.sql` — таблицы, начальные товары и категории, RLS-политики и Storage bucket.
- Обновлённые HTML/JS/CSS-файлы магазина — загрузка каталога из Supabase и вход в панель по 12 нажатиям на логотип.

## Настройка Supabase

1. В Supabase открой **Authentication → Users → Add user**. Создай пользователя с email администратора и цифровым паролем не короче 8 цифр. Для реального магазина используй длинный PIN (лучше 12+ цифр) и включи подтверждение пользователя, если панель предлагает этот переключатель.
2. Открой `supabase-config.js`. Вставь Project URL и публичный **publishable/anon key** из **Project Settings → API Keys**. В `adminEmail` укажи тот же email, что создал на предыдущем шаге.
3. Открой `supabase-setup.sql` в Supabase **SQL Editor**. Замени `admin@example.com` на тот же email и выполни весь SQL после создания пользователя. Он добавит этого Auth-пользователя в список администраторов.
4. В проекте уже включён публичный просмотр картинок и товаров, но изменение данных и загрузка/удаление изображений доступны только администратору через RLS.

В браузерном коде используй только публичный ключ Supabase. **Не вставляй `service_role` или secret key** в `supabase-config.js`.

## Перенос файлов в свою копию магазина

Распакуй архив в корень скачанного репозитория и согласись заменить одноимённые файлы. Сохрани существующую папку `images` — SQL добавляет текущий каталог с путями к этим изображениям. После этого открой папку магазина в VS Code и запусти `index.html` через расширение **Live Server** (не открывай страницу двойным щелчком как `file://`).

На главной странице быстро нажми логотип **12 раз в течение 10 секунд**. Откроется `admin.html`. Введи созданный цифровой пароль. В панели можно добавлять, изменять и удалять категории/товары; изображения можно загрузить при создании или изменении. Удаление категории удаляет её товары.

Если категория или товар создаются без фото, запись сохранится; для категории картинка необязательна, для товара можно добавить фото позже при редактировании.

## Полезно знать

- Это фронтенд без собственного сервера; защиту операций выполняют Supabase Auth и политики RLS в базе/Storage.
- Для магазина в интернете адрес Supabase, публичный ключ и auth redirect/site URL должны быть настроены для домена сайта в Supabase.
- Каталог остаётся привязан к текущей кнопке заказа, которая пока показывает номер-заглушку в `script.js`; замени его на рабочий номер или отдельную форму заказа.
